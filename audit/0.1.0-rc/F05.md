# F05 — standalone skip vs train-like evidence

## Standalone `cbc-event` CI

F05 is skipped on the standalone repository CI because there is no sibling
`public-release` checkout. This is an environment condition, not a waiver. The
skip is visible as `skipped 'CBS read-only checkout is not available'` in the CI
log and in `raw/f05-local-skip.stdout`.

## Train-like temp layout

A temp layout was created with:

```text
tmp-cbc-train-f05/
  cbc-event/                 # copy of this repository
  public-release/tools/
    release_body_v17.py      # extracted from real CBS commit
```

The CBS body generator was extracted from the real CBS commits `04c9f8b` and
`1ee6476` (the current CBS HEAD does not contain the file). The actual F05 test
was run in that layout:

- `raw/f05-train-like-04c9f8b.stdout`: `Ran 1 test ... OK`
- `raw/f05-train-like-1ee6476.stdout`: `Ran 1 test ... OK`

Both outputs contain:

```text
## NOT_UPLOADED
- cbc: NOT_UPLOADED — declared as attached but not uploaded
```

This uses real CBS source and the real CBC test, not a hand-written body.
However, it is a **train-like checkout**, not the actual CBS v1.7 release-train
CI job. The full train job was not available in this workspace.

## Boundary

If the actual CBS v1.7 release-train job skips F05, integration acceptance is
**incomplete**. The train-like run above is evidence for the code path, not a
substitute for that job.
