# F05 — standalone skip vs train requirement

## Standalone `cbc-event` CI

F05 is skipped on the standalone repository CI because there is no sibling
`public-release` checkout. This is an environment condition, not a waiver.
The skip is visible as `skipped 'CBS read-only checkout is not available'` in
the CI log and in `raw/f05-local-skip.stdout`.

## Train requirement

The CBS v1.7 release-train integration CI must check out CBS (with the CBS
body-generator source present) and run F05 for real. If the CBC job in that
train also skips F05, integration acceptance is **incomplete**; it must not be
reported as a pass.

source file. The file exists in historical CBS commits `1ee6476` and
