## Reproduce

```bash
cd audit/0.1.0-rc
PYTHONPATH=../.. python run_real_cases.py
```

The harness builds the chain with CBC's `build_manifest` and appends the
appendix with `render_appendix`; it does not hand-write links.

## R01 local-test-index caveat

`local_r01_result.json` has `anchor_scope=remote` because the code entered the
remote-release branch. The transport is the local test index, **not GitHub**.
The summary field `scope` in that JSON says `local test index, not GitHub`; do
not read `anchor_scope=remote` as a public upload proof.
